# Sitio Web: Árboles de la Zona Central de Chile


Este proyecto es una página web informativa e interactiva sobre la flora nativa del ecosistema mediterráneo y bosque esclerófilo de la zona central de Chile, basada en información técnica y de conservación de fuentes públicas (como el Ministerio del Medio Ambiente MMA y CONAF).

## Estructura de Archivos
- `index.html`: Estructura principal, contenido semántico, secciones informativas y modal de detalles.
- `styles.css`: Hojas de estilo adaptativas (Responsive Design) con una paleta de colores natural e inspirada en la vegetación chilena.
- `script.js`: Lógica interactiva para la filtración por tipo de hábitat, buscador dinámico en tiempo real y desplegable de fichas botánicas completas.

## Características de la Web
1. **Diseño Responsivo**: Adaptado para computadores, tablets y celulares.
2. **Interactividad**: Buscador por palabras clave y filtro dinámico por tipo de bosque (Esclerófilo, Higrófilo, Estado de Conservación).
3. **Fichas Botánicas**: Detalle de especies emblemáticas como el Peumo, Quillay, Boldo, Belloto del Norte, Litre, Palma Chilena, entre otros.
4. **Cero Dependencias Externas Complejas**: Construido con HTML5, CSS3 y JavaScript vanilla.
